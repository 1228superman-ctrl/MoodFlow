# 验证证据

- [windows-t10.log](windows-t10.log) 记录 Windows 实际运行的三个异常注入和 DPAPI 测试。
- [windows-static.log](windows-static.log) 记录配置、语法、设备 USB 识别与原生编译前置检查。
- [windows-t09.log](windows-t09.log) 记录真实登录尝试的 HTTP 403 和独立连通性检查。日志仅含通用错误码。
- [package-verification.log](ci/package-verification.log) 记录最终 IPA 的 SHA-256 及结构复核。两种包的 Xcode 与打包原始日志随本地交付包提供，也可在 [GitHub Actions 成功运行](https://github.com/1228superman-ctrl/MoodFlow/actions/runs/44663667728) 查看。

编译以可复核的 GitHub 运行记录和 Xcode 原始日志取证。待补真机截图包括 WatchBridge 双端安装结果、两端启动画面、定位同意／拒绝、录音时长，以及续签前后事件 ID。将截图原件留在本机，对外分享前遮挡身份、健康值、坐标和设备 ID。
